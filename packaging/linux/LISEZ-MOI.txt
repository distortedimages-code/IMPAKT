IMPAKT — installation sous Linux
================================

Dans ce dossier, lancez :   ./install.sh
- le plugin VST3 va dans ~/.vst3 (là où Bitwig, Reaper, Ardour… le trouvent) ;
- l'application dans ~/.local/share/IMPAKT, avec la commande « impakt » et une entrée de menu.
Pour mettre à jour : relancez install.sh depuis la nouvelle archive. Pour retirer : ./uninstall.sh

L'interface a besoin de WebKitGTK (libwebkit2gtk-4.1) et le réseau de libcurl : install.sh vous
dit s'il en manque. Mode d'emploi : https://distortedimages-code.github.io/IMPAKT/

In this folder run ./install.sh (VST3 in ~/.vst3, the app in ~/.local/share/IMPAKT, no root needed).
